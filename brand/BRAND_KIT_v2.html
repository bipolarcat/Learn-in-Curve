01 — The Mark

The curve becomes a route between two stops.

Same idea as v1 — the S-curve stays — but it's now framed like a stamped travel ticket: gold departure/arrival dots, thick ink-and-gold ring, tilts on hover like it's being picked up off a table.

Minimum size 28px. Clearspace = half mark height. The gold ring never changes color; the ink circle never becomes a gradient.

02 — Palette

Deeper, less "safe."

Pushed every tone one notch darker/richer than v1 so it reads as vintage print, not pastel decor.

03 — Typography

Fraunces italic, pushed harder. Space Mono for the ticket stuff.

v1's Fraunces was too polite. Going bold-italic by default for headlines gives it the swash energy that was missing. Space Mono handles anything that should feel "stamped" — codes, labels, counters.

04 — The Journey (gamification)

A route, not a mascot.

Instead of cute characters and confetti, progress is a route being traveled — closer to a transit map than a kids' app. The path draws itself in; the current stop pulses.

05 — Voice

07 — Mascot

A masked raccoon, not a corporate blob.

Raccoons already wear a mask in nature — putting a caped cowl on top of that is a near-free joke, and it keeps "gamified" from tipping into mascot-cute. Use it in empty states, streak milestones, and loading moments; never as permanent UI chrome.

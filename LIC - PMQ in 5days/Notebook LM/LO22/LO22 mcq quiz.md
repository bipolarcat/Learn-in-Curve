**Question 1:** What are project budgets primarily created from?
A) Risk registers
B) Stakeholder communication plans
C) Estimates
D) Quality assurance reports
**Answer:** C. Budgets are created from estimates, looking at the approximation of time and cost to complete the scope of work.

**Question 2:** Which of the following is a key reason that estimates are used in the project profession?
A) To finalize the project scope
B) To support judgements about value for money for the chosen solution
C) To eliminate all project risks
D) To replace the need for an iterative life cycle
**Answer:** B. Estimates are used to support judgements about value for money for the solution chosen.

**Question 3:** Estimates are an essential input into creating which of the following, which in turn provides the cost view of the project?

B) A risk breakdown structure
C) A quality management plan
D) A benefit realization map
**Answer:** A. Estimates are an essential input into creating a resource schedule which then provides the cost view of the project.

**Question 4:** When creating a budget, why is it important to know when different types of costs will hit the project?

D) To transition the project into an iterative life cycle
**Answer:** B. Knowing when costs will hit the project allows the project manager to budget accordingly, such as timing funding drawdowns to cover payment milestones.
